About the COWLS data

The data release lives in the GitHub repository. Lenses are grouped into tier folders: M25 (the 17 spectacular, confirmed lenses of COWLS II) and S00–S12 (418 candidates, named by visual-inspection score). The catalogue also lists 5 P18 rows: known lenses from prior work included in the catalogue for completeness; they have no COWLS data folder.

Catalogue

The file catalogue.csv has 440 rows (435 candidates with a data folder plus the 5 P18 lenses) and the following columns.

Basic information

  • code: unique identifier for the candidate.
  • score: visual inspection score (the tier folder, e.g. M25, S07, P18).
  • ranking: the individual visual-inspection grades behind the score.
  • ra, dec: right ascension and declination of the candidate (degrees).

COSMOS-Web archival data (if available)

  • lens_spec_z: lens galaxy spectroscopic redshift.
  • lens_cw_photo_z_med: lens galaxy photometric redshift.
  • lens_cw_stmass_med: lens galaxy stellar mass, $\log_{10}(M_\star / M_\odot)$.

PyAutoLens modeling results

  • einstein_radius: Einstein radius of the candidate (arcsec).
  • F115W_lens_magnitude_ab, F150W_lens_magnitude_ab, F277W_lens_magnitude_ab, F444W_lens_magnitude_ab: lens galaxy magnitudes.
  • F115W_source_magnitude_ab, F150W_source_magnitude_ab, F277W_source_magnitude_ab, F444W_source_magnitude_ab: delensed source galaxy magnitudes.
  • F115W_magnification, F150W_magnification, F277W_magnification, F444W_magnification: magnification factors.

Individual lens data

Each candidate folder <tier>/<code>/ contains:

Image files

  • 1_rgb_fit_summary.png: RGB images, source reconstructions and lens-subtracted images (lenses with a model).
  • 2_visual_first_round.jpeg: image from the first round of visual inspection.
  • 3_multi_wavelength_dataset.png: image, masked image, lens-subtracted image, S/N map and source S/N map.
  • 4_sie_fit.png: lens model components inferred by PyAutoLens for all bands.
  • 5_source_reconstruction.png: delensed source reconstructions.
  • 6_rgb.png: RGB image of the candidate (every lens).
  • For a subset of lenses: positions.png / positions_mge.png (lensed source positions) and source_near_lens_centre.png / source_near_lens_centre_mge.png with source_near_lens_centre.json.

.fits files (for each band: F115W, F150W, F277W, F444W)

  • data.fits: JWST imaging data.
  • noise_map.fits: RMS noise map.
  • psf.fits: point spread function (PSF).
  • psf_71x71.fits: PSF on a larger 71×71 pixel grid (psf_31x31.fits is also present for a few lenses).
  • mask_extra_galaxies.fits: mask removing extra galaxies from the data (most lenses).
  • result/: PyAutoLens model outputs, e.g. lens_light.fits, source_light.fits, source_reconstruction.fits and sie_model.results (lenses with a model).

Metadata and results files

  • info.json: metadata (e.g. RA, Dec, lens redshift, primary waveband).
  • result.json: PyAutoLens modeling results (lenses with a model).
  • positions.json: lensed source positions used in modeling.

Archival data

The folders archive_space and archive_ground inside each lens folder contain COSMOS archive data:

  • archive_space: high-resolution data (e.g. HST F814W, MIRI F770W).
  • archive_ground: ground-based data (e.g. HSC, UltraVISTA, IRAC).

Important considerations

  • Geometric alignment: archival data may have astrometric offsets and rotations relative to the JWST data.
  • Noise maps: noise maps are instrument-specific and may require conversion to RMS noise values.
  • Pixel scale conversion: pixel scales vary and must be extracted from the .fits headers.

PRIMER

The PRIMER survey provides additional deep JWST and HST wavebands for a subset of 32 lenses. The file primer.csv lists these candidates (its directory column gives each lens folder), and the primer/ folder in each of those lens folders contains the corresponding data.

If you use PRIMER data, please cite Dunlop J. S., et al., 2021, PRIMER: Public Release IMaging for Extragalactic Research, JWST Proposal. Cycle 1, ID. #1837, and the official PRIMER data release paper if it is available.

Physical quantities

Geometry

A $(y,x)$ Cartesian coordinate system is established, centred on the light or mass profile:

$$y_{\rm shift} = y - y_{\rm centre}, \quad x_{\rm shift} = x - x_{\rm centre}$$

The shifted coordinates are then rotated by the position angle $\phi$, defined counter-clockwise from the positive x-axis:

$$y_{\rm rot} = y_{\rm shift} \cos\phi - x_{\rm shift} \sin\phi, \quad x_{\rm rot} = y_{\rm shift} \sin\phi + x_{\rm shift} \cos\phi$$

The rotated coordinates are converted to elliptical coordinates using the axis-ratio $q$ of the light or mass profile:

$$\xi = \sqrt{x_{\rm rot}^2 + \frac{y_{\rm rot}^2}{q^2}}$$

Instead of $\phi$ and $q$, the following “elliptical components” are used:

$$\epsilon_{1} = \frac{1 - q}{1 + q} \sin 2\phi, \quad \epsilon_{2} = \frac{1 - q}{1 + q} \cos 2\phi$$

To convert between these components and the position angle / axis-ratio:

$$q = \frac{1 - {\rm fac}}{1 + {\rm fac}}, \quad \phi = \frac{1}{2} \arctan\left(\frac{\epsilon_{1}}{\epsilon_{2}}\right), \quad {\rm fac} = \sqrt{\epsilon_{1}^2 + \epsilon_{2}^2}$$

Mass model

The SIE lens mass model is defined by:

$$\kappa(\xi) = \frac{1}{1 + q^{\rm mass}} \left( \frac{\theta^{\rm mass}_{\rm E}}{\xi} \right)$$

where $\theta^{\rm mass}_{\rm E}$ is the Einstein radius of the mass model. This is a scaled Einstein radius used to improve modeling efficiency in PyAutoLens.

The effective Einstein radius $R_{\rm Ein,eff}$, the definition more commonly used in the literature, is:

$$R_{\rm Ein,eff} = \sqrt{\frac{A}{\pi}}$$

where $A$ is the area enclosed by the tangential critical curve, ensuring consistency across different mass density profiles.

External shear

The external shear field is parameterized by two components $\gamma_{1}^{\rm ext}$ and $\gamma_{2}^{\rm ext}$. The magnitude and orientation are:

$$\gamma^{\rm ext} = \sqrt{(\gamma_{1}^{\rm ext})^2 + (\gamma_{2}^{\rm ext})^2}, \quad \tan 2\phi^{\rm ext} = \frac{\gamma_{2}^{\rm ext}}{\gamma_{1}^{\rm ext}}$$

Magnitudes

For the MGE lens light and the Voronoi source reconstruction, see the papers and the PyAutoLens documentation for detailed descriptions of the profiles. Lens and source magnitudes are AB magnitudes:

$$M_{\rm lens} = -2.5 \log_{10}(F_{\rm lens}) + Z, \qquad M_{\rm source} = -2.5 \log_{10}(F_{\rm source}) + Z$$

where $F_{\rm lens}$ and $F_{\rm source}$ are the fluxes of the lens and source galaxies and $Z$ is the zero-point (the zero_point calibration of the data). The magnification factor $\mu$ is:

$$\mu = \frac{F_{\rm source,\,image\text{-}plane}}{F_{\rm source}}$$

where $F_{\rm source,\,image\text{-}plane}$ is the total flux of the lensed source galaxy in the image plane (i.e. magnified by the lens galaxy).
